Now Let's take a step back to the artifact definition. Let's brainstorm how this should be. I think it should be different types of data with different utility and functions. Common traits to all artifacts should be:
- cleanliness. It should be data ready to be used by users in tabular or chart form
- readable size and level of detail. The rule should be that all the data it contains should be ok to be in a table or a chart in a pdf report. Not huge datasets or super multidimensional.
- it should be mutable (but maybe in the future will be immutable/versioned).
- it must describe a single dimension of a phenomenon. So it shouldn't be in general more than a table. In case you want to describe multiple dimensions, you can create multiple artifacts.
- it can be of different types: extraction from some good available source (so with the quality of being more raw but strictly rooted) or it can be a work in progress very useful data that we really would like to have to describe a phenomenon but we don't have because we have no unified source, or no source at all. So we need some estimation, and some empty points.

## Available Tools

You have access to these MCP (Model Context Protocol) tools:

- **search_engine**: Search the web for information about the asset
  - Use to find official sources, Wikipedia articles, annual reports, news
  - Search in the local language when appropriate

- **scrape_as_markdown**: Extract and read webpage content
  - Use to analyze official government sites, company pages, reports
  - Converts HTML to readable markdown format

- **query_wikipedia**: Query Wikipedia articles directly
  - Use to get structured information about the asset
  - Provides reliable overviews and basic facts

Use these tools systematically to research the asset from multiple angles and gather comprehensive information.
